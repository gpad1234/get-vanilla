# Vanilla Web Starter

A simple starter project built with plain HTML, CSS, and JavaScript.

## Step-by-step guide

1. Start with structure
   - Add semantic HTML sections for the hero, content, and footer.
2. Style the layout
   - Use CSS variables, spacing, and responsive rules to give the page a clear visual system.
3. Add simple interaction
   - Use JavaScript for tiny features such as a theme toggle or form handling.
4. Document as you go
   - Keep notes in the README so future changes are easier to understand.

## Learning path

- HTML: learn how tags build the page structure.
- CSS: learn how styling makes the page visually clear and responsive.
- JavaScript: learn how small scripts add behavior and interactivity.

## Run locally

Open [index.html](index.html) in a browser, or start the Node-based server:

```bash
npm start
```

The server will print the actual local URL it is using, usually http://127.0.0.1:3000 or another available port.
